# Manifesto

I am a retail trader, statistically I have a disadvantage to large hedge funds. These hedge funds have algorithms. These algorithms are meant to manipulate the price and fail my setups. I want to use these tools you're building me to spot the psychological manipulation through news, and fake setups. So this is what I want you to do. Build the algorithms in this app that the same hedge funds use. When you're all done make sure it's all good through Vercel. When designing the actual dashboard, I put some reference pictures. And download these GitHub skills to help: https://github.com/kadoa-org/congress-trading-monitor, https://github.com/JerBouma/FinanceDatabase, https://github.com/coding-kitties/investing-algorithm-framework, connect TradingView as well to this.

## Design references (summarized)
1. Simply Wall St home: dark navy, three columns (portfolios / insights feed / market performance), tabbed 7D-1M-3M-1Y-3Y-5Y switches, blue tickers, green/red only for direction.
2. Investment dashboard: big headline numbers on top, progress bar, area chart, donut, dense card grid.
3. Institutional risk terminal: very dense tables, small type, tabbed panels (P&L / Equity / Assets / Positions), Live/Historical toggles.
